## 2026-10-16 — Inquiry modal interaction and accessibility hardening

The inquiry modal was tightened so the booking flow behaves predictably during repeat visits and unreliable network conditions. The client component now centralizes modal open and close behavior, clears stale success and error state when a new inquiry begins, returns focus to the element that opened the dialog, closes on Escape, and exposes the navigation relationship through `aria-controls`.
